# Changelog

All notable changes to this project will be documented in this file.

The version format uses a project-specific four-component scheme (`MAJOR.MINOR.PATCH.REVISION`), where the fourth component designates corrective revisions.

## [0.1.0.1] — Corrective

### Fixed
- Replaced abbreviated license with the complete standard MIT License (`LICENSE`).
- Clarified the provenance of CoreS3-RuleBot test evidence (`docs/TEST_RESULTS.md`).
- Removed or explicitly labeled unsupported empirical claims as illustrative examples (`ILLUSTRATIVE`).
- Unified Quality Gate statuses across all templates and workflows (`PASS`, `FAIL`, `BLOCKED`, `NOT_EVALUATED`, `NOT_APPLICABLE`).
- Unified test execution statuses (`NOT_RUN`, `PASS`, `FAIL`, `BLOCKED`, `NOT_APPLICABLE`) and resolved contradiction in test engineer decision rules.
- Clarified Antigravity compatibility requirements: removed mandatory assumptions regarding proprietary slash commands.

### Changed
- Simplified shared multi-project workspace integration without duplicating the toolkit.
- Added quick daily prompt sections to all eight reusable prompt files.
- Documented document single responsibility and rules for proportional documentation updates.
- Clarified selective document loading for skills and profiles.
- Refined `AGENTS.md` rules of engagement for pre-flight verification, strict scope compliance, and proportional reporting.

### Scope
- Preserved all 8 original skills.
- Preserved all 7 original workflows.
- Preserved all 12 original templates.
- Preserved all 6 original technical profiles.
- Preserved all 8 original prompt files.
- Preserved pedagogical example CoreS3-RuleBot.
- Preserved bilingual documentation (English and French).
- No new skills, workflows, or technical profiles added.
- No executable runtime components or daemons added.
- No external dependencies introduced.
